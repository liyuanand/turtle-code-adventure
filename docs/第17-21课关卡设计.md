# 第 17–21 课：列表主题冒险

每课三个小关；代码选项每次进入关卡打乱，同一道题的顺序在选答与重试期间固定。学生完成任务后，场景图片和列表数据同步变化。通关后有三幕主题剧情。

口令：第 17 关 2018；第 18 关 2019；第 19 关 2020；第 20 关 2025；第 21 关 2026。

## 第 17 课 · 三角洲·补给撤离行动

创建列表、识别数据类型，用整数索引取值

知识点：列表创建 []、字符串 / 整数 / 浮点数 / 布尔值、索引从 0 开始、列表[索引]、int(input())

1. **建立混合补给清单**：哪一行创建了包含文字、整数、浮点数和布尔值的列表？
   - 运行结果：补给列表创建成功
2. **索引 0 对应第一件物资**：要取出第一件物资“医疗包”，应使用哪行代码？
   - 运行结果：医疗包
3. **输入索引，提取撤离补给**：选择能把输入转换为整数再取物资的代码，随后亲自输入 0～2。
   - 运行结果：物资提取成功

列表用方括号创建，元素之间用逗号分隔，可以保存字符串、整数、浮点数、布尔值等数据。索引从 0 开始；列表索引需要整数，input() 得到的是字符串，要用 int() 转换。本关有 3 件物资，可用索引是 0、1、2。

## 第 18 课 · 我的世界·切片造桥工坊

掌握切片起点、终点、步长与默认步长 1

知识点：列表切片、[开始:结束]、[开始:结束:步长]、包含开始、不含结束、默认步长 1

1. **截取连续三块桥面材料**：需要索引 1、2、3 的石块、铁块、金块，应选哪个切片？
   - 运行结果：['石块', '铁块', '金块']
2. **每隔一块挑选装饰材料**：从索引 0 开始，每次索引增加 2，取出木块、铁块、钻石。
   - 运行结果：['木块', '铁块', '钻石']
3. **找出省略步长的等价写法**：哪一项与 blocks[1:4] 得到完全相同的子列表？
   - 运行结果：默认步长是 1，两种写法得到相同列表

切片从列表中截取多个元素，并返回一个新的子列表。列表[开始:结束] 包含开始索引、不包含结束索引；第三个参数步长表示每次索引增加多少。省略步长时默认是 1，最后一个冒号也可以一起省略，例如 blocks[1:4] 与 blocks[1:4:1] 相同。

## 第 19 课 · 王者荣耀·阵容焕新与烟花

使用索引赋值修改列表，结合输入和随机库

知识点：列表[索引] = 新值、修改前后对照、input() 自选内容、拆解步骤、random.choice()、turtle.pencolor()

1. **把射手位置换成辅助**：要把索引 1 的“射手”换成“辅助”，哪行代码正确？
   - 运行结果：第二个位置已替换，列表仍有 3 个元素
2. **自己决定换谁、换成谁**：先选出完整的修改步骤，再输入位置与新英雄名称。
   - 运行结果：自选阵容已更新
3. **从颜色列表随机选择烟花颜色**：六条烟花线每次都从 colors 中随机选色，应补入哪行？
   - 运行结果：烟花已按本次随机选出的颜色绘制

修改列表用 列表[索引] = 新值，只替换指定位置，其他元素保持不变。可以拆成“输入位置 → 转成整数 → 输入新值 → 按索引修改 → 展示结果”。random.choice(colors) 会从颜色列表中随机选择一个元素，可配合 turtle.pencolor() 绘制不同颜色的烟花线条。

## 第 20 课 · 蛋仔派对·积分收集赛

用 append() 添加数据，用 for 遍历列表

知识点：空列表 []、append() 追加、for 元素 in 列表、for i in range()、int() 与整数字符串、input()

1. **收集三次输入的整数积分**：哪段代码能创建空列表，再把三次输入转换为整数并追加到末尾？选好后亲自输入。
   - 运行结果：三个整数已经按输入顺序追加
2. **遍历列表，依次通过赛道**：想依次输出彩虹门、弹跳板、终点，哪段代码会遍历每个列表元素？
   - 运行结果：彩虹门；弹跳板；终点
3. **修好积分转换器**：下面哪个字符串能够直接被 int() 转成整数？
   - 运行结果：字符串 "12" → 整数 12

[] 创建空列表，append(新元素) 会把元素添加到列表末尾。for item in items 会将列表中的元素依次赋值给循环变量 item。input() 返回字符串；int("12")、int("-3") 可以转换，int("3.5") 和 int("蛋仔") 会报错。这里讨论的是字符串转换：int() 也能接收浮点数，例如 int(3.5) 得到 3。

## 第 21 课 · 保卫萝卜·炮塔列表守卫战

使用 len()、pop()、负向索引与 turtle 圆弧

知识点：len() 元素个数、pop() 删除并返回、负向索引 -1、列表遍历、circle(半径, 角度)、bgpic() 背景图片、print() 与算术

1. **清点炮塔：个数不是最后索引**：列表里有三座炮塔，哪条代码输出炮塔个数 3？
   - 运行结果：3
2. **用负向索引撤下末尾炮塔**：要删除并得到最后一座“冰冻星”，哪行代码正确？
   - 运行结果：取回冰冻星，剩下两座炮塔
3. **遍历两座炮塔，画半圆防护**：已剩下两座炮塔。要每座画一个半径 60 的半圆，应在循环中填入哪行？
   - 运行结果：瓶子炮；太阳花；画出 2 个半圆，总能量 4

len(列表) 返回元素个数。负向索引 -1 表示最后一项、-2 表示倒数第二项。pop(索引) 删除并返回指定元素；不写参数的 pop() 默认删除最后一项。turtle.circle(半径, 角度) 可画圆弧，180° 是半圆；bgpic() 可设置已准备好的背景图片。遍历列表可依次处理每座炮塔，算术运算可以计算所需能量。

## 教学边界

- 代码卡判题对应固定任务；列表操作由页面根据实际输入计算展示。不是任意 Python 代码执行器。
- 第 17 课输入整数索引，第 19 课输入索引与新英雄，第 20 课模拟循环的三次输入；不把字符串输入假装成整数。
- 索引越界、小数字符串、空输入应显示具体原因，并允许修正。
- 切片不修改原列表；列表修改保持其他位置不变；append() 追加到末尾；pop() 删除并返回元素。
- 随机选择允许颜色重复；半圆角度为 180°；int("3.5") 会报错，但 int(3.5) 为 3。
- 第 21 课附带 garden.gif 示例背景图片，示例下载后需与 Python 文件放在同一目录。
